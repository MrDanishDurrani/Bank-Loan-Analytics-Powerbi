# Bank Loan Analytics Dashboard
## Project Overview
This project is an interactive Bank Loan Analytics Dashboard developed using Microsoft Power BI.
The dashboard provides insights into loan applications, funded amounts, received amounts, loan quality, repayment status, interest rates, borrower characteristics, and loan purposes.
The project contains two main dashboard pages:
- Summary
- Overview
## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV
## Key KPIs
- Total Loan Applications: 38,576
- Total Funded Amount: 435.8M
- Total Received Amount: 473.1M
- Average Interest Rate: 12.05%
- Average DTI Ratio: 13.33%
## Dashboard Pages
### 1. Summary
The Summary page provides an overview of:
- Good Loan Applications
- Bad Loan Applications
- Good Loan Percentage
- Bad Loan Percentage
- Funded Amount vs. Received Amount
- Loan Status
- Average Interest Rate
### 2. Overview
The Overview page provides analysis of:
- Monthly Loan Applications
- Loan Applications by State
- Loan Applications by Loan Term
- Loan Applications by Home Ownership
- Loan Applications by Loan Purpose
## Key Insights
The dashboard can be used to analyze:
- Monthly loan application trends
- Distribution of good and bad loans
- Funded amount compared with received amount
- Loan application patterns by state
- Loan term distribution
- Borrower home ownership
- Loan purposes
- Interest rate patterns
- Debt-to-income ratio
## Project Features
- Interactive Power BI dashboard
- KPI cards
- Slicers and filters
- Trend analysis

- Donut chart
- Bar charts
- Treemap
- Loan quality analysis
- Interactive navigation between dashboard pages
